# Abdulrhman — Portfolio & Workspace

## معرض المشاريع العشرة

[افتح دليل المعرض والمشاريع](services/portfolio-studio/README.md) — عشرة نماذج تفاعلية مستقلة الفكرة، بهوية مشتركة، وحفظ محلي واختبارات. ملفات الدخول لكل مشروع داخل `services/portfolio-studio/projects/` وصور الواجهات داخل `screenshots/`. مشاريع بورتفوليو بمساعدة AI، وليست أنظمة إنتاج أو أعمالًا لعملاء.

## مركز تنظيم العمل

هذا المستودع يحتوي دليل التنظيم العام. لا يحتوي على سجلات العملاء أو البريد أو وثائق Drive الخاصة.

## ابدأ هنا

- [خريطة الملفات](docs/STRUCTURE.md): أين يوجد كل نوع من العمل.
- [طريقة إدارة العمل](docs/WORKFLOW.md): الحالة، الاختبارات، التسليم والأرشفة.
- [حدود النشر](docs/PUBLISHING.md): ما يمكن رفعه إلى المستودع العام.

## حل برمجي منشور

- [مولّد CHANGELOG من Git](services/changelog-bounty/README.md): حل مرشّح لطلب مكافأة معلن، مع 15 اختبارًا وعينة حقيقية. ليس عقدًا أو دفعة مؤكدة.

- [فلتر الأوامر الخطرة](services/bash-guard/README.md): مرشح طلب 100$؛ اختبارات محلية، وليس حاجز أمان شاملًا.
- [قالب Next.js وSQLite](services/next-sqlite-template/README.md): مرشح طلب 75$؛ البناء والاختبارات ناجحة، وتجربة السياق داخل Claude Code غير منفّذة.

## التقسيم

| القسم | الغرض | النشر |
|---|---|---|
| `docs/` | التوثيق العام | عام |
| `scripts/` | فحوص التنظيم | عام |
| `outreach/` | البحث والعروض وتوثيق المراسلات | محلي خاص |
| `services/` | المشاريع والنماذج قيد مراجعة النشر | محلي، لا يُرفع تلقائيًا |
| `tools/` | الأدوات الموجودة قيد المراجعة | محلي، لا يُرفع تلقائيًا |
| `google_drive/` | نسخ العمل المحلية من وثائق Drive | محلي خاص |
| `private-admin/` | الفهرس الداخلي والجرد وسجل التنظيم | محلي خاص |

الملفات الخاصة محفوظة، وليست محذوفة. `.gitignore` يمنع إضافتها عرضًا؛ لكنه ليس تشفيرًا أو نسخة احتياطية.

## فحص قبل النشر

```sh
python3 scripts/check_public_boundary.py
```

يفحص أسماء الملفات المتتبّعة والمجهزة للإضافة مقابل قائمة نشر محدودة. لا يغني عن مراجعة محتوياتها بحثًا عن بيانات خاصة.

لا يُعد وجود مشروع أو عينة هنا دليلاً على تعاقد أو قبول أو دفع. حالة العمل الفعلية محفوظة في السجل الخاص.
