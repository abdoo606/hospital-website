# طريقة إدارة العمل

1. مراجعة آخر سجل خاص والمراسلات المرتبطة قبل أي إرسال جديد.
2. إعطاء كل فرصة حالة صريحة: بحث، مؤهلة، عرض مرسل، متفق عليها، قيد التنفيذ، مسلّمة، مقبولة، مدفوعة، متوقفة، مغلقة.
3. لا تحول «مرسل» إلى «متفق عليه»، ولا الرد الآلي إلى قبول، ولا السعر المقترح إلى مبلغ مستحق.
4. لكل تسليم: مصدر الطلب، نسخة المصدر، ملفات التغيير، تعليمات التشغيل، نتائج الاختبارات وحدودها.
5. تثبيت السعر والنطاق وقواعد القبول قبل بدء عمل مدفوع. لا تغيير للإنتاج أو إنفاق أو صلاحيات بلا تفويض مناسب.
6. تحديث الفهرس الخاص عند تغيّر الحالة، مع إبقاء السجلات السابقة كما هي.
7. الأرشفة لا تلغي الالتزامات السابقة. لا حذف دائم في عمليات التنظيم.

## قواعد الملفات

- الجولة: `round-NNN`؛ لا تعاد تسمية الجولات القديمة.
- النسخة: تاريخ أو رقم إصدار واضح؛ لا ملفات متكررة تحمل اسم «نهائي» فقط.
- سجل النقل: معرف الملف، الاسم/المجلد السابق، الاسم/المجلد الجديد، ونتيجة العملية.
- لا تُرفع قوائم الاتصال أو مرفقات البريد إلى مستودع عام.
