## Setup (Node 22, npm, supported native SQLite build environment)
1. From this folder: `npm ci`.
2. Run `npm run db:migrate && npm test && npm run typecheck && npm run build`.
3. Run `npm run dev` (development) or `npm start` (after a production build).

Default database: `data/app.sqlite`. Production must provide a persistent local path through DATABASE_PATH. A local C++ toolchain, Python and matching Node headers are needed if a prebuilt better-sqlite3 binary is unavailable. In this sandbox, using installed headers via `npm_config_nodedir=/usr/local` allowed the native build without disabling TLS verification.
